This site is a set of Markdown files built by Jekyll on GitHub Pages. It follows a small design system I call Monograph: warm paper, a Garamond text face, and tables ruled like a LaTeX `booktabs` table. Typography carries the hierarchy, so there are no cards, shadows or icons.

## Writing a page

Every project lives in `_projects/` and every post in `_posts/`. Second-level headings are numbered automatically as sections, so prose can refer to §2, and third-level headings become subsections like 2.1.

### Figures

Images placed with the figure include are numbered in page order and captioned in italics.

### Tables

A plain Markdown table renders with heavy rules top and bottom and a hairline under the header.

| Quantity          | Value  | Unit |
|:------------------|-------:|:-----|
| Discharge voltage |    300 | V    |
| Anode flow        |    2.1 | mg/s |
| Thrust            |   19.6 | mN   |

### Equations

Set `math: true` in the front matter and write TeX between double dollar signs.

$$
I_{sp} = \frac{T}{\dot{m}\, g_0}
$$
